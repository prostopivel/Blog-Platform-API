# BlogPlatform

## Задание

## Запуск

1. Установить проект на локальное устройство. Необходимые приложения - Git, Docker.
2. Открыть директорию <code>Blog-Platform-API\docker</code> в терминале.
3. Выполнить <code>docker-compose up -d --build</code> и дождаться билда.
4. API работает на URL <code>http://localhost:5000</code>, Swagger UI: <code>http://localhost:5000/swagger</code>.
5. Отдельные микросервисы доступны на портах: 5001 (Auth), 5002 (Blog), 5003 (Analytics).
6. Некоторые эндпоинты защищены авторизацией, доступ имеется после авторизации.

Реализовать блог с возможностью комментировать и лайкать посты. Пользователь выбирает интересные ему темы (теги) и получает новостную ленту по выбранным темам.

## Функционал:

1. Модели: пользователь, блог, тег, комментарий и др.
2. Авторизация упрощенная.
3. Графики: количество постов по дате, по пользователю, по тэгам и др.

## Требования:
1. Приложение представляет собой WebAPI сервис. Разрабатывается на языках: C# (.NET Core)
2. Хранение данных происходит в БД. PostgreSQL
3. Доступ «Сервера» к данным БД происходит выполнением прямых SQL команд без использования какой-либо ORM.
4. Для тестирования API можно использовать Postman или аналогичные инструменты.
